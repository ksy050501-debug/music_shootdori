# 슛돌이 가락 만들기

6학년 음악 가락 창작 수행평가용 웹앱입니다. `index.html` 한 파일로 동작하며 Vercel에 그대로 배포할 수 있어요.

## 선생님 설정 (`index.html`의 `<script>` 맨 위)

- `CANVA_URL` — Canva 제출 링크. 넣으면 사진 저장 뒤 「Canva에 올리러 가기」 버튼이 나타나요.
- `LYRICS` — 가사. 띄어쓰기는 무시되고 한 글자씩 음표 13개 아래에 붙어요.
- `TEMPO` — 빠르기 (기본 120).

## 제출 흐름

학생이 가락을 만들고 「제출하기 (사진 저장)」를 누르면 악보 사진(PNG)이 저장되고, 그 사진을 Canva에 올립니다.
사진 아래의 제출 코드를 페이지 맨 아래 「선생님용: 제출 코드로 들어 보기」에 넣으면 그 가락을 반주와 함께 들을 수 있어요.
